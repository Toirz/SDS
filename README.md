# NUS SDS Datathon 2027

## Requirements

- Node.js 24 (`.nvmrc`: 24.20.0)
- npm 11.19.0

## Current stack

- Next.js 16.4.0 (App Router)
- React 19.3.0
- TypeScript 5.9.3
- Tailwind CSS 4.3.3

## Run locally

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## Run production build

```bash
npm ci
npm run build
npm run start
```

Open http://localhost:3000.
